# HSdeck The Great Dark Beyond 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## API 경량화 및 편집 규칙 (2026-11-14)

- 배포 데이터는 `cards.json` 목록, `data/<CARD_ID>.json` 카드별 한국 날짜·능력치/효과 이력, `art/` 일반 카드 원화, `golden/` 황금 원화·애니메이션 및 `frame/` 프레임·재질·셰이더 데이터입니다. 토큰/자식 카드·황금 및 프레임의 원본 ID와 연결을 보존합니다.
- `render.json`·`history.json`·`*-date.json` 집계는 중복이므로 게시/커밋 금지입니다. 임시 빌드 테스트에서는 사용해도 저장소에 복원하지 않습니다. 신규 schema/호환 래퍼는 작성하지 않습니다.
- 최초 날짜는 한국 시간 실제 대전 사용 가능일입니다. 베타는 북미 시간 환산, 모험은 지구 실제 개방, 이벤트는 행사 개시일 기준이며 사전 탑재일은 제외합니다. 원본이 비날짜형이면 최초 스펙·출처를 보존하며 무손실 변환합니다.
- 이후 날짜는 변경 필드만 입력하고, 잘못된 날짜 키는 삭제·통합합니다. 표시 개행은 `<br></br>`, 원시 데이터의 줄바꿈은 그대로 둡니다. 원화·황금 애니메이션·프레임 바이너리는 임의 재가공하지 않습니다.
- 빌드에 필요한 `tools/`, `release-policy.json`, `.github/` 등은 실제 참조를 확인하기 전에는 삭제하지 않습니다.
